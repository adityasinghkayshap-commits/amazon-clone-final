# Amazon Clone (React + Vite)

## Run locally
1. Install Node.js.
2. Run `npm install`
3. Run `npm run dev`

## Deploy on Vercel
- Framework Preset: Vite
- Build Command: `npm run build`
- Output Directory: `dist`

IMPORTANT: Keep `index.html` and `package.json` in the repository root. Keep all React components and CSS inside the `src` folder. Do not upload the ZIP itself.
